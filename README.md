# F2-diploma-project

Кваліфікаційний проєкт бакалавра зі спеціальності F2 «Інженерія програмного забезпечення».

- **Робоча назва теми:** Подієво-орієнтована система гейміфікованого трекінгу читання з модулем розпізнавання книжкових полиць
- **Робоча назва продукту:** BookOff
