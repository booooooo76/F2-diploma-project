## Нефункціональні вимоги (NFRs Matrix)

Повний перелік — таблиця 1.2 у [1_analysis.md](1_analysis.md) і розділ 3 [srs.md](srs.md). Цільове середовище — одна хмарна VM, 4 vCPU, 8 ГБ RAM.

| Категорія | Ключові обмеження |
|---|---|
| Продуктивність | 100 RPS; p95 ≤ 300 мс, p99 ≤ 800 мс для синхронних запитів; помилки < 0,5 % |
| Асинхронна обробка | Обробка фото полиці p95 ≤ 30 с; затримка подія → проєкція p95 ≤ 5 с |
| Якість розпізнавання | precision ≥ 0,85, recall ≥ 0,60 на власному наборі 40–60 зображень |
| Безпека | Argon2id; JWT access 15 хв, одноразовий refresh 30 днів; TLS 1.2+; Token Bucket 60 запитів/хв; OWASP ASVS L1 |
| Надійність | Доступність ≥ 99,0 %; at-least-once з ідемпотентною обробкою; Circuit Breaker, Retry, резервне джерело Open Library |
| Інфраструктура | Docker Compose, OpenTofu; щоденне резервне копіювання PostgreSQL, RPO ≤ 24 год, RTO ≤ 4 год |
